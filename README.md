# ups18650-12v-1.2a-lx-2bups-01

Корпус для ДБЖ роутера на базі модуля UPS18650 12V/1.2A (LX-2BUPS).

Побудован у OpenSCAD. Потрібна зовнішня бібліотека case.scad.

В репозіторії в наявності готова 3D модель у форматі 3mf.
Для друку використовуються параметри по замовченню, для fdm принтера з соплом 0,4 мм.

Також додан файл з деякими можливими змінами для модуля UPS18650 12V/1.2A (LX-2BUPS).
